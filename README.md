# Education Management Portal

An AI-powered Education Management Portal designed to manage academic activities for students, teachers, and administrators.

## Overview

The Education Management Portal provides a centralized platform for managing courses, classes, assignments, attendance, examinations, grades, and academic records.

The system also includes an AI-powered academic intelligence module that analyzes student performance and provides insights such as weak subjects, academic risk levels, performance trends, and personalized recommendations.

## Features

### Student

* View enrolled courses
* Track course progress
* Submit assignments
* View attendance
* View examination results
* View grades
* Monitor academic performance
* Receive AI-based recommendations
* Identify weak subjects and academic risks

### Teacher

* Manage courses and classes
* Record student attendance
* Create and manage assignments
* Evaluate assignments
* Manage examinations
* Enter student marks
* Monitor student performance
* Identify students at academic risk
* View AI-generated academic insights

### Administrator

* Manage students and teachers
* Manage courses and classes
* Manage assignments and examinations
* Manage academic records
* View institution-level analytics
* Generate academic reports
* Monitor academic risks
* View AI-powered insights

## AI Performance Analysis

The system calculates an academic performance score using:

```text
Performance Score =
Attendance × 0.25
+ Assignment Score × 0.30
+ Examination Score × 0.45
```

Risk levels are determined using attendance and academic performance.

```text
80–100  Excellent
65–79   Good
50–64   Needs Improvement
0–49    At Risk
```

The system also identifies weak subjects and generates recommendations based on the student's academic data.
